### 1-2. 핵심 문제

1. **평면적 나열**: 61개 메뉴가 9그룹에 균등 분배되어 일상 업무(회원승인, 문의답변)와 희귀 작업(교사 affiliation 분리, 학번 연동)이 같은 레벨에 존재
2. **역할 무관 노출**: 5역할(학회장/부학회장/기획운영/연구학술/대외협력) 각각의 업무와 메뉴 진입점이 매핑되지 않음. 모든 staff가 61개 전부 탐색
3. **중복/유사 기능 산재**: 
   - "학술활동 대시보드" vs "활동" 그룹 세미나/프로젝트/스터디 (집계 vs 개별)
   - "회원 검증" / "포트폴리오 검증" / "졸업논문 매핑" (검증류 3개 산재)
   - "아카이브 홈" + 가이드 4종 + 개념/변인/측정도구 (9개가 한 그룹 — 과도)
4. **1회성 마이그레이션 메뉴 상주**: "신청자 학번 연동", "교사 affiliation 분리"는 데이터 정리용 1회성 도구인데 상시 메뉴에 존재
5. **온보딩 그룹 단독 1개**: 메뉴 그룹이 단일 항목만 가지면 시각적 낭비
6. **처리 대기 vs 사이드바 이중 동선**: ReviewQueueBanner(5건)가 사이드바 상단에 있으나, 같은 항목이 사이드바 개별 메뉴에도 배지로 중복 표시

## 5. 개편안: 운영 라이프사이클 기반 재배열

### 5-1. 설계 원칙

1. **업무 흐름 순서**: 신입 유입 -> 승인 -> 온보딩 -> 활동 운영 -> 콘텐츠 생산 -> 성과 분석
2. **빈도/중요도 우선**: 일상 핵심 메뉴는 항상 펼쳐진 상태, 드묾/관리 메뉴는 접힘 기본
3. **역할 친화**: 역할별로 자주 쓰는 메뉴가 한 그룹에 모이도록
4. **그룹 상한 7개**: 인지 과부하 방지 (밀러의 법칙 7+-2)
5. **처리 대기 배너 유지**: ReviewQueueBanner는 현행 유지 (교차 영역 알림으로 가치 있음)

### 5-2. 신규 메뉴 구조 (7그룹, 사이드바 노출 ~35항목)

```
[처리 대기 배너] ← 현행 유지 (회원승인, 미답변문의, 피드백, 아카이브검수, 콘텐츠초안)

-- (1) 홈 -- [항상 펼침]
   홈 대시보드          ← 시즌 카운트다운 + 할일 + 처리 대기
   업무노트             ← 인수인계, 업무수행철

-- (2) 회원 -- [일상 핵심, 항상 펼침]
   회원관리 [배지]      ← 가입 승인
```

## 6. 역할별 "빠른 진입" UI 제안

### 6-1. 콘솔 홈 대시보드에 역할별 바로가기 카드

현재 콘솔 홈에는 시즌 카운트다운 + 처리 대기 + 할일이 있다. 여기에 **"내 역할 바로가기"** 카드를 추가한다.

```
┌─────────────────────────────────────┐
│  내 담당 업무 (기획운영)             │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌────┐ │
│  │세미나│ │스터디│ │수요  │ │모임│ │
│  │관리  │ │관리  │ │조사  │ │조율│ │
│  └──────┘ └──────┘ └──────┘ └────┘ │
│  업무 매뉴얼 보기 →                  │
└─────────────────────────────────────┘
```

**구현 조건**: 조직도(useOrgChart)에서 현재 로그인 사용자의 userId와 매칭되는 OrgPosition을 찾고, 그 role/title에 따라 staff-manual-seed의 플랫폼 경로를 표시. 조직도에 미배정이면 일반 "빠른 진입" 표시.

### 6-2. 사이드바 역할 필터 (장기)

사이드바 상단에 역할 필터 토글을 두어 "내 역할 메뉴만 보기"를 선택하면 해당 역할의 주담당 메뉴만 표시. 전체 보기로 전환 가능.

## 8. 개편 효과 예측

### 정량적

| 지표 | 현재 | Phase 1 | Phase 2 | Phase 3 |
|------|------|---------|---------|---------|
| 사이드바 보이는 항목 | 61 | ~55 | ~35 | ~15 (역할 필터 시) |
| 그룹 수 | 9 | 7~8 | 7 | 7 |
| 원하는 메뉴까지 평균 클릭 | 2.1 (그룹 열기 + 스크롤) | 1.8 | 1.4 | 1.0 (바로가기) |
| 1회성 도구 상시 노출 | 2 | 0 | 0 | 0 (자동 숨김) |

### 정성적

- **신임 운영진 온보딩**: 61개 메뉴 -> 역할별 4~8개 메뉴 우선 노출로 학습 곡선 대폭 단축
- **일상 업무 효율**: 처리 대기 배너 + 역할 바로가기로 "오늘 할 일"이 1클릭에 보임
- **시스템 유지보수**: 그룹/항목 구조가 운영 라이프사이클과 일치하여 신규 메뉴 추가 시 배치 기준 명확
