## C. 관점별 고유 제안 (추가 가치)

- **아키텍처**: 권한 모델을 `adminOnly`/`presidentOnly` 2-flag → **단일 `minRole` 체계**(ROLE_HIERARCHY 재사용, 상속 체인)로 개선. orphaned 라우트(/console/todos·research/journal 등) 정리. NAV_GROUPS를 `console-nav-config.ts`로 분리(테스트 용이). 중복 AuthGuard 제거.
- **운영기획**: **역할별 빠른 진입 카드**(조직도 userId 매칭 → 5역할 주담당 메뉴). 권한 정합(회원관리·신청승인 페이지 접근은 staff 완화, 쓰기만 admin 게이트). 검증류 3개(회원·포트폴리오·졸업논문) 단일 탭 페이지 통합.
- **UX**: **모바일 Drawer**(현재 수평 탭바 사용 불가 수준). 사이드바 **검색 필터**(client-side). 즐겨찾기 핀. 검수 배너를 홈 그룹 아래로.

## D. 메인 추천 통합안 (3관점 절충, 7그룹)

academic/* 정합(아키)을 존중하되 14개 과밀(UX·기획)을 피해 활동/학사 분리:

1. **홈** — 홈·업무노트·**인사이트**(홈 이동)
2. **회원** — 회원관리·문의·피드백·잠재회원·연락망·신규체크리스트·운영진설정 · [접기]관리도구(검증3·마이그레이션2)
3. **학술 활동** — 활동총괄·세미나·프로젝트·스터디·대외학술대회·모임·해커톤·수요조사·신청승인
4. **학사** — 수강과목·졸업요건·연구활동·학회비·발급문서·인지디딤판·학기별로드맵·논문심사연습
5. **콘텐츠·아카이브** — [콘텐츠 8] + [아카이브: 홈·검수큐·가이드4·개념/변인/측정·콘텐츠갭]
6. **AI & 자동화** — AI포럼·챗봇설정·AI에이전트(통합)
7. **시스템**(presidentOnly) — 사이트설정·학사일정·감사로그·Cron·실험실

**단계**: Phase 1(라벨·재배치, ~1일, URL 무변경) → Phase 2(접기 서브섹션·아카이브 서브내비·AI통합, ~3일) → Phase 3(역할카드·모바일Drawer·권한minRole, 별도 스프린트)

## E. 결정 요청
①학사+활동 통합 vs 분리 ②AI 독립그룹 vs 시스템하위 ③인사이트 홈 이동 여부 ④콘텐츠+아카이브 통합 여부 — 넷만 정해주시면 그에 맞춰 Phase 1(즉시 반영)부터 구현합니다. 무응답 시 D의 추천 통합안으로 진행 가능.
