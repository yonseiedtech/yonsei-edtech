# 26년 후기 연세교육공학회 운영진 업무 매뉴얼 (초안)

**임기**: 2026-2 (26년 후기)
**작성**: 2026-07-27 · 현재 LIVE 플랫폼(yonsei-edtech.vercel.app) 기능 기준
**근거 조사**: `docs/plans/_staff-structure-survey.md`

> 이 문서는 5개 운영진 역할의 임무를 **현재 플랫폼에 실제로 존재하는 기능**에 매핑한 실행 매뉴얼이다.
> 각 역할 섹션은 그대로 플랫폼 업무수행철(`handover_docs`)로 시드되어 `/console/handover?role=<직책>` 에서 열람된다.

---

## 0. 조직·권한 개요

| 계층 | 저장소 | 내용 |
|------|--------|------|
| 권한 게이트 | `User.role` (`president` / `staff`) | 콘솔·운영 기능 접근 이진 권한 |
| 조직 직책 | `site_settings/org_chart:2026-2` (`OrgPosition`) | 직책명·담당자(userId)·담당업무(duty)·인수인계(handover) |
| 업무수행철 | `handover_docs` (`HandoverDocument`) | 역할별 임무·워크플로우·TO-DO 체크리스트 |
| 운영 업무 | `staff_tasks` / `admin_todos` | 담당자 배정·상태 추적 |

**핵심**: 세부 직책(기획/연구/대외 등)은 `User.role`에 없다. `president`는 학회장 1인, 나머지 4역할은 모두 `staff` 권한으로 동일하며, **직책 구분은 조직도(OrgChart)와 업무수행철(role)에서만** 관리한다.

### 26년 후기 운영진 매칭표

| 직책(OrgPosition.title) | 담당자 | User.role | 조직도 role | 업무수행철 role |
|------------------------|--------|-----------|------------|----------------|
| 학회장 | 김혜진 | `president` | `president` | `학회장` |
| 부학회장 | 한지혜 | `staff` | `vice_president` | `부학회장` |
| 기획·운영담당 | 김남영 | `staff` | `team_member` | `기획운영` |
| 연구·학술담당 | 수연 | `staff` | `team_member` | `연구학술` |
| 대외협력담당 | 유지은 | `staff` | `team_member` | `대외협력` |

> ⚠️ **계정 권한 배정 주의**: 위 매칭표의 `User.role` 부여(예: 김혜진→president, 나머지→staff)와 조직도 `userId` 연결은 **실제 회원 계정을 변경하는 되돌리기 어려운 작업**이다. 매뉴얼 문서·시드 기능 자체는 계정을 건드리지 않으며, 계정 매칭은 운영진 확인 후 `/console/settings`(조직 설정)·`/console/handover`(운영진 교체) UI에서 수행한다.

## 1. 학회장 (김혜진) — `role: 학회장`

**한 줄 정의**: 학회 전체 방향을 정하고, 운영진 업무를 조율하며, 최종 승인 게이트를 책임진다.

**카테고리**: routine · **우선순위**: high

### 담당 업무 (duty)
- 학기 운영 방향·일정 총괄, 운영진 역할 배분·조율
- 회원 가입 최종 승인, 공지·뉴스레터 발행 승인
- 조직도·권한(운영진 교체) 관리

### 플랫폼 워크플로우
1. **운영 현황 점검** — `/staff` 홈 대시보드에서 팀 스냅샷·처리 대기 큐 확인 (매주)
2. **처리 대기 소진 조율** — 회원 승인·미답변 문의·아카이브 검수 항목을 담당 운영진에게 배분
3. **공지/뉴스레터 발행** — `/console` 콘텐츠에서 초안 검토 후 발행 승인
4. **조직·권한 관리** — `/console/settings`(조직도), `/console/handover`(운영진 교체 탭)
5. **인사이트 리뷰** — `/admin/insights`에서 연결 KPI·여정 완주율 월간 점검

### 인수인계 TO-DO
- [ ] 26년 후기 운영진 4인 조직도 배정 확인 (`/console/settings`)
- [ ] 학기 운영 일정(세미나·모임·대내 학술대회) 캘린더 확정

## 2. 부학회장 (한지혜) — `role: 부학회장`

**한 줄 정의**: 학회장을 보좌하고, 운영진 실무 진행을 챙기며, 학회장 부재 시 대행한다.

**카테고리**: routine · **우선순위**: high

### 담당 업무 (duty)
- 운영진 업무 진행 상황 취합·독려, 회의 준비·주재 보조
- 회원 관리 실무(가입 승인 1차 검토), 공지 초안 작성
- 학회장 위임 사항 대행

### 플랫폼 워크플로우
1. **팀 업무 취합** — `/staff` 홈 대시보드 "내 할당 업무"·팀 스냅샷으로 운영진 진행률 확인
2. **회원 승인 1차** — `/console` 회원 관리에서 가입 신청 검토 → 학회장 최종 승인 전 정리
3. **회의 운영** — 진행 미팅 타이머(`ProgressMeeting`)로 운영진 회의 아젠다·시간 관리
4. **공지 초안** — `/console` 공지에서 초안 작성 → 학회장 발행 승인 요청
5. **모임 일정 조율** — `/gatherings` 일정 투표로 운영진 모임 시간 확정

## 6. 반영 방식 (플랫폼 연동)

1. **업무수행철 시드**: 위 5개 역할 섹션은 `HandoverDocument`(role·duty·workflow·todos·category·priority)로 변환되어 `/console/handover` 업무수행철 탭에서 role별로 열람된다. 운영진이 콘솔의 시드 버튼으로 1회 생성한다.
2. **조직도 반영**: `org_chart:2026-2`에 5직책(학회장·부학회장·기획운영·연구학술·대외협력)을 `duty` 포함해 배치한다.
3. **회원 매칭**: 조직도 각 직책의 `userId`에 실제 회원을 연결하고, 학회장→`president`·나머지→`staff`로 권한을 부여한다. **이 계정 변경 단계만 운영진 확인 후 수행**한다.

### 업무매뉴얼 ↔ 회원 연동 흐름
```
회원(User) ──role──▶ 권한 게이트(president/staff)
   │
   └─userId─▶ OrgPosition(직책·duty·handover)
                 │
                 └─role매칭─▶ HandoverDocument(임무·workflow·todos)
                                 │
                                 └─assigneeId─▶ StaffTask(개별 업무 추적)
```

## 7. 회원 매칭 절차 (A 방식 — 운영진 직접 배정)

> 계정 권한·조직도 배정은 되돌리기 어려운 변경이라, 자동 반영 대신 **운영진(주로 학회장)이 콘솔 UI에서 직접** 수행한다. 아래 3단계를 순서대로 진행한다.

### 1단계 — 업무수행철 시드 (1회)
- `/console/handover` → **업무수행철** 탭 → **"26년 후기 매뉴얼 시드"** 버튼 클릭
- 5역할 매뉴얼(임무·워크플로우·TO-DO)이 생성된다. 이미 있는 역할은 자동 스킵.

### 2단계 — 권한 부여 (User.role)
- `/console/handover` → **운영진 교체** 탭(TransitionView)
- 김혜진 → **회장(president)**, 한지혜·김남영·수연·유지은 → **운영진(staff)** 로 지정
- ⚠️ 이 단계가 실제 계정 권한을 바꾼다. 대상 회원이 정확한지 확인 후 진행.

### 3단계 — 조직도 직책 배정 (OrgPosition.userId)
- `/console/settings/org-chart` (조직도 편집기)
- 직책 추가/편집: 학회장·부학회장·기획운영·연구학술·대외협력
- 각 직책의 **담당자(userId)** 에 해당 회원을 연결하고, **담당 업무(duty)** 에 위 매뉴얼 요약을 기입
- 저장 시 `org_chart:2026-2` 로 학기 스코프 저장됨

### 확인
- 배정 후 `/console/handover?role=<직책>` 에서 각 담당자가 자기 역할 매뉴얼을 열람할 수 있는지 확인
- 공개 조직도(홈)에 5직책·담당자가 반영됐는지 확인
